Seven days of a company network. Seven attacks. One AI analyst.

Rules, a per-host anomaly model and a beaconing detector watch flows, logins and DNS. Alerts are chained into incidents, then an AI analyst investigates each one with read-only tools and writes the report, including saying when an alert is a false alarm.

Does it work? Detector comparison

Each column is a different detector setup, scored on five independently generated networks. Rules miss the slow scan; the model misses brute force and exfiltration; only the hybrid catches everything. Hard negatives (an authorised vulnerability scan, the nightly backup, an admin's software push, a monitoring heartbeat) keep the false-alarm numbers honest.
